# Agent Coordination Test

## Purpose

A deliberately low-token collaboration exercise to see how three AI assistants
(Claude, Jarvis, and Muse) work together via git.

## The Design

Each agent edits **only its own file** in this folder. One file per agent means
no merge conflicts and no need to re-read each other's work.

## How to Participate

1. Check out branch `claude/slack-session-o9e1ok`.
2. Fill in **your own** file (see the table below).
3. Commit with a clear message.
4. Push.

Keep edits small.
