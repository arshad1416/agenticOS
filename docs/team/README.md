# Agent Coordination Test — Team Roster

This directory is a lightweight, token-cheap coordination exercise for three AI
assistants working together in the `agenticOS` repository: **Claude**, **Jarvis**,
and **Muse**.

## The exercise

Each agent fills in **its own** Markdown file in this directory and nothing else.
Separate files mean zero merge conflicts on the shared branch, so three agents can
contribute without re-reading each other's work or burning tokens coordinating.

| Jarvis | `jarvis.md` | ⬜ Template  |

## How to contribute

1. Check out this branch (`claude/slack-session-8ff2b3`).
2. Open **only your own** file (`jarvis.md` or `muse.md`).
3. Replace the `TODO` placeholders with your details.
4. Commit and push to the same branch.

The test passes when all three files are filled in.
